# GetShopReply 开发店性能诊断

日期：2026-10-20。Lighthouse 13.5.0，移动端模拟，在同一台电脑、同一开发店预览主题完成三组交替测量。报告对应整合前提交 `caceedc9142e09d383b1be17ff6e97262c83891b`，不是后续整合版本的验收。

| 组别 | 拦截组件脚本 | 正常加载组件 |
| --- | ---: | ---: |
| 1 | 83 | 80 |
| 2 | 90 | 88 |
| 3 | 93 | 97 |
| 性能分数中位数 | 90 | 88 |
| TBT 中位数 | 400 ms | 467.5 ms |

正常加载时检测到两次组件资源请求；第一组传输约 4.96 KB，后两组主要命中缓存。测试期间没有发送聊天问题或调用 AI。正常加载组没有出现明显布局偏移，CLS 约 0.000071。

这些结果只能作为诊断，不能据此断言组件让商店更快或已满足 Shopify 性能审核。对照通过拦截 `shopreply-loader.js` 请求实现，未在主题编辑器真实关闭开关；为了保留开发店密码登录，使用 `disableStorageReset=true`，缓存、测量顺序、开发隧道和后台浏览器任务都可能影响结果。各组有明显波动。

正式验收仍需在最终整合版本、稳定后端入口、同一主题下，真实关闭/开启 App Embed，控制缓存和设备条件后重测。三组完整 HTML 与 JSON 报告及摘要位于 `performance/`。
